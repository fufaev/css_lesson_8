# Практическая работа №6: Возможности CSS3 для оформления веб-страниц

В рамках этого задания вам предстоит освоить современные декоративные возможности CSS3: позиционирование, трансформации, псевдоэлементы и анимацию без использования JavaScript.

## 📋 Техническое задание

Ваша задача — выполнить задания по созданию двух декоративных элементов на основе методических материалов (`ribbon.html` и `photo1.html`). 

### 🛡️ Антиплагиат (условия вариативности)
Чтобы работа была зачтена, вы **обязаны кастомизировать** код под свой индивидуальный вариант. Студенты, сдавшие идентичные стили, к защите не допускаются.

1. **Наклонная ленточка (`ribbon.css`):**
   * **Цвет ленты:** Запрещено использовать стандартный красный `#d93131`. Выберите свой цвет (Hex/RGB).
   * **Угол наклона и позиция:** Измените угол наклона (в методичке `45deg`) на любой другой в диапазоне от `30deg` до `60deg`. Скорректируйте свойства `top` и `right` так, чтобы лента сидела идеально.
   * **Эффект загиба (`:before` и `:after`):** Цвет «загибов» должен соответствовать фону вашей страницы (или быть чуть темнее цвета ленты для реалистичности). Поменяйте толщину рамки `border` под ваш угол наклона.

2. **Фотогалерея (`photo1.css`):**
   * **Индивидуальный масштаб:** Измените начальный `scale(0.8)` и финальный `scale(1.2)` на свои значения (например, `0.7` и `1.3` или `0.85` и `1.15`).
   * **Эффект тени:** Вместо стандартного `gray` настройте размытие и цвет тени (`box-shadow`) индивидуально.
   * **Контент:** Дополните демонстрационные изображения Минска еще 4 любые другие тематические картинки Минска (папка `images/`).

3. **Осознанность (Блок документации):**
   * Внутри ваших файлов `ribbon.css` и `photo1.css` в самом конце добавьте CSS-комментарий `/* Своими словами */`, где в 2-3 предложениях объясните:
     1. За счет каких свойств CSS создается трехмерный эффект «загиба» ленты за край картинки?
     2. Какую роль играет свойство `transition-duration` при наведении (`:hover`) на картинку?

Все файлы вашей работы должны находиться **строго внутри вашей персональной папки**. Изменение файлов в корне репозитория или в папках других студентов приведет к автоматическому отклонению PR.

```text
Фамилия_Имя_Группа/
├── css/
│   ├── ribbon.css          # Кастомизированные стили ленточки + мини-отчет в комментариях
│   └── photo1.css          # Кастомизированные стили галереи + mini-отчет
├── images/                 # Ваши уникальные изображения для галереи и ленты
├── ribbon.html             # Разметка для ленточки
└── photo1.html             # Разметка для фотогалереи
```
